PdfToAll — PDF to DOCX / XLSX / PPTX, offline
=============================================

Portable build: nothing to install, nothing is written outside the folder
except the files you ask for.

Quick start
-----------
  pdftoall.exe convert report.pdf -o out
  pdftoall.exe convert report.pdf -f xlsx
  pdftoall.exe info report.pdf
  pdftoall.exe --help

Windows SmartScreen may warn about an unsigned executable: the build is not
code-signed yet. "More info" -> "Run anyway", or build from source.

Everything runs locally: no network access, no uploads, no telemetry.

Source and issues: https://github.com/vkust/PdfToAll
